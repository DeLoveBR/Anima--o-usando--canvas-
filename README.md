# 🎨 Animação Interativa com HTML5 Canvas e JavaScript

## 📌 Sobre o projeto

Este projeto foi desenvolvido como atividade prática da disciplina **Desenvolvimento em JavaScript**, do curso de Ciência da Computação da Faculdade Anhanguera.

A aplicação consiste em uma página web com uma animação interativa utilizando o elemento **HTML5 Canvas** e JavaScript. Durante a execução, círculos e retângulos se movimentam pela tela, alteram suas cores continuamente e mudam de direção quando o usuário clica no quadro da animação.

## 🚀 Funcionalidades

- Desenho de círculos e retângulos utilizando Canvas 2D.
- Movimentação automática dos objetos.
- Alteração contínua das cores.
- Detecção dos limites do Canvas para mudar a direção dos objetos.
- Interação com o usuário por meio do evento de clique do mouse.
- Animação contínua utilizando `requestAnimationFrame()`.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização e organização visual.
- **JavaScript:** lógica da animação e interatividade.
- **Canvas 2D:** criação e manipulação dos elementos gráficos.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.
4. Observe a animação e clique dentro do quadro para alterar as cores e a direção dos objetos.

Não é necessário instalar dependências adicionais.

## 📚 Conhecimentos praticados

Durante o desenvolvimento, foram praticados conceitos importantes de JavaScript:

- Manipulação do Canvas e do contexto 2D.
- Criação e utilização de funções.
- Uso de arrays e `forEach()`.
- Atualização de propriedades dos objetos.
- Estruturas condicionais.
- Eventos de mouse.
- Animação com `requestAnimationFrame()`.

## 🎯 Objetivo

O objetivo deste projeto foi aplicar na prática os conhecimentos de JavaScript e manipulação gráfica no navegador, desenvolvendo uma animação simples e interativa.
